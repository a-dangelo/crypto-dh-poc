# Reading layout

Audience: an expert in formal methods and cryptography.
The opening theorem states the result and hypotheses. Subsequent chapters supply
the refinement, games, sampling comparison, and trust boundary.

Use restrained typography and a neutral paper palette. Mathematical prose is
serif; navigation is sans-serif; Lean is monospace. Avoid promotional labels,
summary cards, introductory tutorials, and repetitive scope disclaimers.

At wide widths, each formal node pairs prose on the left with imported Lean
source on the right. At narrow widths, prose precedes source. Code scrolls within
its column, all headers wrap, and focus indicators remain visible.
